# Бренд Skyline Digital

Концепция и токены — `docs/Design System.md` («Horizon over Tashkent»).
Здесь только файлы. Цвета не дублируем: источник истины — `src/app/globals.css`.

| Файл | Где использовать |
| --- | --- |
| `logo-mark.svg` | фавикон, иконка приложения, водяной знак в углу видео. Прозрачный фон |
| `logo-square.svg` | аватарки Telegram / Instagram / Facebook / YouTube. Фон `night` |
| `logo-horizontal.svg` | шапка сайта, подпись в письмах, обложки. Прозрачный фон, текст наследует `currentColor` |
| `logo-square-1024.png` | растровый вариант от владельца, для площадок без поддержки SVG |
| `colors.json` | три акцентных цвета для внешних инструментов |

## Шрифт в SVG

Вордмарк — живой текст с `font-family: Unbounded`. В вебе и в Remotion шрифт
подгружается и всё рисуется верно. Для площадок, которые рендерят SVG без
внешних шрифтов (некоторые каталоги, печать), используем PNG-экспорт.

## Чего пока нет
- Вордмарк в кривых — понадобится только для типографии/печати.
- Обложки под конкретные площадки (YouTube 2560×1440, LinkedIn 1128×191) —
  соберу из `logo-horizontal.svg`, когда дойдём до шага 6.
