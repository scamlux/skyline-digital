# Эталон дизайна — `artifact-skyline.html`

Это **пиксельный эталон** новых вариантов главной (прототип из Claude Artifacts,
`claude.ai/artifact/3sa6opoSTEwRxMNrTxbesp`). Один самодостаточный HTML: три версии
в переключателе + демо-админка. **Источник правды по виду, токенам, таймингам и коду
эффектов** при переносе в реальный Next.js (см. `docs/plan-site-versions.md` и
`docs/TZ-site-versions.md`).

## Как пользоваться
- Открыть файл в браузере (двойной клик или `file://…`). Всё работает офлайн,
  картинки вшиты как data-URI.
- Справа внизу — демо-панель: **Версия сайта** (Старый / Studio / Референс) и
  **Акцент бренда** (5 цветов). Переключение меняет `data-ver` на `<html>` и
  CSS-переменные `--acc` / `--acc-ink`.
- При переносе компонента **копировать точные значения** (цвета-переменные, `cubic-bezier`,
  длительности, радиусы, клип-пути), а не пересобирать «на глаз».

## Карта (что где искать в файле)
- `#ver-old` — «старый» дизайн (в репо НЕ переносим: это текущий боевой код).
- `#ver-studio` / классы без префикса — **Studio** (светлый, Onest, stacking-панели,
  параллакс-hero, карусель проектов, анимированные услуги, scroll-progress процесс).
- `#ver-ref` / классы `.r-*` — **Референс** (award-style тёмный: preloader, кастомный
  курсор `#rcursor`, кинетик-hero с ротатором, полноэкранное меню, индекс проектов с
  плавающим hover-превью `.r-preview`, depth-«Философия» на `position:sticky`,
  **FLIP-открытие кейса из кликнутой строки** `openCase()`, pinned horizontal «Что мы делаем»).
- `#accent` + массив `THEMES` (в конце, IIFE) — пресеты акцента.

## Акцент = основной цвет (важно)
`--acc` (основной) и `--acc-ink` (светлый/контрастный) заданы на `:root`; от них
перекрашивается **почти всё цветное** в обоих новых вариантах:
- Studio опирается на `--acc` / `--acc-ink` напрямую.
- Референс: `--r-acc: var(--acc-ink)`, свечения/градиенты — `color-mix(... var(--r-acc) ...)`,
  курсор-ринг — `var(--acc-ink)`. Переключение акцента перекрашивает hero-glow, CTA,
  строки, статистику, hover-состояния, индикаторы, курсор.
- «Старый» вариант свой акцент (`--o-amber`/`--o-pink`) и акцентом бренда НЕ управляется.

## Нюансы, уже отловленные в прототипе
- `position:sticky` для depth-эффектов ломается, если на родителе `overflow:hidden` —
  на обёртке Референса `overflow` не ставить.
- Всё уважает `prefers-reduced-motion` (preloader, курсор, depth, карусель, параллакс).
- Проверено Playwright на 1440px и 390px: без ошибок консоли и горизонтального скролла.

> на реальных данных/i18n/3D, с бюджетом LCP ≤ 2.5 с.
