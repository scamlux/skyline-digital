# i18n

Trilingual UI via **next-intl**. Locales: **ru** (default), **en**, **uz**.

## Config (`src/i18n/`)

- `routing.ts` — `locales: ["ru","en","uz"]`, `defaultLocale: "ru"`,
  `localePrefix: "as-needed"` (ru unprefixed; `/en`, `/uz` prefixed).
- `navigation.ts` — locale-aware `Link`, `redirect`, `usePathname`, `useRouter`.
- `request.ts` — loads the matching `messages/<locale>.json` per request.
- `src/proxy.ts` — the next-intl middleware (Next 16's renamed `middleware`).

## Messages

`messages/ru.json`, `en.json`, `uz.json` — flat namespaces: `nav`, `footer`,
`home`, `services`, `projects`, `project`, `about`, `contact`, `calc`,
`estimate`, `notFound`, `meta`. All three kept in sync.

## Conventions

- Pages call `setRequestLocale(locale)` for static rendering, then
  `getTranslations(ns)`.
- Client components use `useTranslations(ns)`.
- The hero headline marks its gradient word with `*asterisks*` in the message
  string (parsed in `page.tsx`) — see [[Design System]].
- `LocaleSwitcher` in the [[Header|Header]] links the same pathname across locales.

## Note

Copy inside `messages/*.json` is written per-language (not machine-translated
placeholders). Keep keys identical across the three files.
