# Нишевые сайты по подписке — сводный ресёрч

Дата: 2026-10-27 · Статус: ресёрч завершён, решение по первым нишам и демо — за владельцем
Продолжает: `VERTICAL-SITES-SUBSCRIPTION-2026-10.md` (рынок, радар, интеграции).
Полные отчёты по направлениям (с источниками): `docs/business/niche-research/`.

## 0. Решения владельца (зафиксировано)

- **Цена — 50 $/мес, один тариф, не меняется.** Лестница Старт/Бизнес/Про из прошлого документа (§5) снята.
- **Приоритет качества: дизайн → удобство → понятность** — для посетителей сайта и для владельца в админке.
- **Дальше:** демо-шаблоны (рестораны, клиники и т.д.) после выбора ниш.

Метки в отчётах: **[П]** — первоисточник, **[В]** — вторичный/вендор, **гипотеза** — вывод без данных. Цифры конверсии без методики мы не использовали.

## 1. Главные выводы

1. **Конкурент слабее, чем кажется, и это шанс.** UzBiznes: 17 категорий и 111 шаблонов, но на деле 139–259 тыс. сум/мес помесячно (105–207 тыс. при годовой оплате) вместо заявленных «от 90 тыс.»; в тарифе салона перечислены «Курьеры, Официанты, Терминалы»; viewport блокирует зум; **нет клиник/стоматологии, фитнеса, автосервиса** ([teardown](niche-research/teardown.md)). Уровень hero у лучших шаблонов (Trattoria Nero, bento-салон) высокий — плохой дизайн нам не поможет, но ясность и честная цена — да.
2. **Побеждаем не функциями, а дизайном и понятностью:** $50 (≈600 тыс. сум) в 2,5–5 раз дороже UzBiznes и в ~3 раза дешевле Popmenu ($159–179+) и Owner ($249 + 5% с заказа). Значит продаём «премиальный вид + понятно + без процента с заказов».
3. **Один движок, два дизайна на нишу.** Все шесть исследователей сошлись: общий скелет (оффер → два CTA → список услуг/меню/курсов с ценой → доказательства → процесс → контакты), одна форма с 3 полями, заявка в Telegram. Ниши различаются «сущностью» и парой наборов токенов — ровно то, что уже умеет наша система вариантов.
4. **Telegram, а не WhatsApp.** Кнопка Telegram и заявка в Telegram владельца — в каждом шаблоне.
5. **Честные границы за $50:** онлайн-оплата Payme/Click/Uzum — платный допуск (нужен мерчант-договор), живой календарь слотов, кабинет результатов в клиниках (персональные данные), календарь занятости отеля, channel manager — не в базе.
6. **Главный риск — поддержка, а не инфраструктура.** Себестоимость хостинга: ~$4,5/сайт при 10 клиентах, ~$0,45 при 100 (расчёт, [cross-cutting](niche-research/cross-cutting.md)); тикет поддержки стоит $25–35 [В] → нужно **< 0,2 обращения на сайт в месяц**: простая админка, сайт «не ломается», шаблон не даёт испортить дизайн.
7. **Срочно для Узбекистана:** по данным отчёта, Сенат 10.09.2026 одобрил смену латиницы (Oʻ→Ö, Gʻ→Ğ, Sh→Ş, Ch→Ç) со вступлением в 2027. **Дату проверить по тексту закона**; шаблонам заранее нужна единая форма хранения текста (U+02BB), нормализация ввода, слой транслитерации, ASCII-slug.

## 3. Рекомендуемый порядок

**Волна 1 — три шаблона, закрывающие самые большие пулы и дыры конкурента:**
1. **Ресторан / кафе** (одна «сущность» — меню) — самый доказанный рынок, самый яркий демо.
2. **Стоматология / клиника** — крупнейший пул в радаре (862) и нет у UzBiznes.
3. **Салон / барбершоп** — второй по размеру пул (601 + спа), нужен для проверки логики «запись к мастеру».

**Волна 2 (после первых клиентов):** автосервис/детейлинг (нет у UzBiznes, легко), учебные центры, фитнес.
**Волна 3:** отели, туризм, фото, юристы, ветеринария. **Недвижимость — по запросу** (каталог).

Принцип: **1–2 качественных шаблона на нишу лучше, чем 23 однотипных** (teardown).

## 4. Планка качества шаблона (15 проверяемых пунктов)

Источник — разбор лучших примеров ([teardown §5](niche-research/teardown.md)); делаем автоматической проверкой в CI там, где можно.

1. Главная ≤ 8 секций, без дублей.
2. Первый экран на 390 и 1440: заголовок, 1 основная CTA, 1 вторичная, чип доверия.
3. Основная CTA одинакова по смыслу везде и повторяется в шапке и внизу.
4. Навигация ≤ 6 пунктов + одна кнопка; без выпадающих меню.
5. Телефон/Telegram в одно касание с любого экрана (sticky-панель на мобильном).
6. Нажимаемые элементы ≥ 44×44 px.
7. Прайс/меню в тексте, не PDF; «от X сум».
8. Контраст ≥ 4,5:1, затемнение под текстом на фото.
9. ≤ 2 гарнитуры, единый набор радиусов, 1 акцентный цвет.
10. Вес главной ≤ 1 МБ, LCP ≤ 2,5 с (4G), CLS ≤ 0,1; hero в AVIF/WebP.
11. Нет всплывающих окон поверх первого экрана.
12. RU/UZ на каждой странице, сохраняет путь; заголовки на узбекском (+25% длины) не обрезаются; без `maximum-scale=1`.
13. Нет бренда платформы на сайте клиента (или серым в подвале).
14. Шаблон отраслевой по сути (блоки, которых нет в универсальном).
15. Страница тарифа: одна цена $50/мес, что входит и чего нет, без «бесплатно».

## 5. Жёсткие правила для всех шаблонов

Сводка из [cross-cutting](niche-research/cross-cutting.md); пороги — из NN/g, Baymard, web.dev, WCAG 2.2.

- **Мобильный первый экран:** описание + Позвонить / Маршрут / Telegram + «Открыто до…».
- **Типографика:** 16 px+, строка ≤ 70 знаков, абзацы ≤ 3 строк, CTA = глагол + результат («Забронировать стол»).
- **Форма:** 3 поля, ошибки рядом с полем, после отправки — «что дальше» и срок ответа.
- **Скорость:** LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1 — блокирующий гейт; Lighthouse ≥ 90 (планка Webflow-шаблонов ниже, 51–70 — нам ставим выше).
- **Токены:** один акцент из проверенных палитр; свободный выбор цвета запрещён — это защита качества («guardrails»).
- **Движение:** 150–300 мс, `prefers-reduced-motion` обязателен.
- **Тексты:** понятный язык, цены прозрачны, микротекст «что будет после клика».

## 6. Дизайн-направления (два на нишу)

Один набор компонентов, два набора токенов (цвет, пара шрифтов, радиусы, плотность). Описания — настроение и логика, не копирование чужих брендов.

| Ниша | Направление А | Направление Б |
|---|---|---|
| Рестораны | **«Тёплая трапеза»** — крем, терракота/горчица, антиква + спокойный гротеск, крупные фото при естественном свете | **«Чистый вечер»** — графит, один тёплый акцент (латунь/медь), геометрический гротеск, меню — аккуратная типографская таблица (риск: контраст) |
| Кафе | **«Витрина»** — светлая тёплая основа, пастельные акценты по категориям, круглые фото-плитки | **«Ремесло»** — крафтовая палитра, плотная типографика, акцент на происхождение |
| Отели | **«Тихий приём»** — спокойная нейтральная гамма | **«Яркий хостел»** — энергичный акцент, быстрое бронирование |
| Туризм | **«Шёлковый путь»** — тёплые тона, крупные карточки направлений | **«Лёгкий старт»** — чистый светлый, фокус на цене «от» и контакте |

## 7. Админка владельца и дашборд (в базе за $50)

- **5 вещей, ради которых заходят:** часы работы, телефон, цены, акция недели, фото. Остальное редко.
- **Один экран — одна задача:** карточки «Часы», «Цены», «Фото», «Акции», а не дерево настроек.
- **Правка на месте** поверх живой страницы (клик по цене — изменил), мобильный и десктопный предпросмотр, автосохранение, одна кнопка «Опубликовать».
- **Предохранители:** нельзя удалить телефон/адрес без замены; предупреждение про слишком маленькое/тёмное фото.
- **Дашборд — 3–5 чисел и фразы** («За неделю 14 заявок, на 3 больше»), плюс **недельный дайджест в Telegram** (Bot API бесплатен).
- **Аналитика:** собственные события в Supabase — $0 за лицензию (Plausible ≈ $950/мес на 500 сайтов — не подходит).
- **Исследований про владельцев малого бизнеса не найдено** — раздел помечен как наш вывод; проверять на 5–10 владельцах.

## 9. Юридические и операционные риски

- **Персональные данные.** С 27.03.2026 обязательная локализация в Узбекистане — только биометрия, генетика, данные абонентов связи; остальное можно хранить за рубежом при условиях. Подзаконные списки не подтверждены → **юрист до продажи клиникам**. Данные о здоровье — «специальные»: форма записи — имя, телефон, время, согласие, без диагнозов.
- **Реклама.** Закон «О рекламе» ЗРУ-776: ненадлежащая/недостоверная реклама, штраф до 70 БРВ; про «до/после» в клиниках прямого текста не нашли → консервативные формулировки, блок лицензии, предупреждение о противопоказаниях.
- **Рекламные SMS** с 01.11.2026 — только с согласия; сервисные напоминания отделять от рекламы.
- **Оплата подписки.** У Payme есть Subscribe API (рекуррентные платежи); для Click/Uzum данных нет → на старте счёт вручную + напоминание в Telegram.
- **Латиница 2027** — см. §1.7.
- **Конкуренция.** UzBiznes (дёшево, много шаблонов), агентства (tipa.uz) — разовые сайты с интеграцией YClients.

## 10. Что не подтверждено (честно)

- Примеры сайтов (Padella, Dishoom и др.) взяты из обзоров, **вживую не открывались**; часть референсов из teardown открыта текстом, **без мобильной проверки** — перед тем как брать за образец, открыть глазами.
- Цены/комиссии Payme, Click, Uzum, YCLIENTS/Altegio в Узбекистане, статус Auto-nazorat, UzFit, Soff CRM как отдельных продуктов.
- Поведенческие метрики по Узбекистану (цифры из США и РФ); вендорские цифры (+25% от фото в меню, 70% мобильного трафика) — в продажах не использовать.
- Рейтинг спроса — наша оценка; подтвердить замером числа компаний в каталогах (2GIS, OLX) и холодным тестом предложения.
- Закон о смене латиницы — проверить дату и текст.

## 11. Следующие шаги

1. **Владельцу:** подтвердить волну 1 (ресторан/кафе, стоматология/клиника, салон/барбершоп) или поменять.
2. Демо-шаблон «Ресторан»: `/[locale]/demo/restaurant` (+ кабинет владельца на демо-данных, `noindex`, плашка «Демо»), два стиля с переключателем, планка качества §4 как тест.
3. Демо «Клиника» — по тому же движку.
4. Параллельно: интервью 10–20 владельцев из радара (цена $50 и «что входит»), консультация юриста по ПДн, проверка закона о латинице.
