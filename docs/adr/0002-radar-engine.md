# ADR 0002 — Radar lead-scanning engine (Phase B)

**Дата:** 2026-09-02 · **Статус:** принято

## Контекст

Фаза B: находить узбекские компании (стоматология / автосервис / салоны красоты)
в публичных каталогах, замерять их веб-присутствие, скорить A/B/C и складывать в
`radar_companies` для холодного аутрича. Управление — `/admin/radar`.

Заявленный источник истины `docs/prompts/build-radar.md` в репозитории
**отсутствует**. По согласованию с владельцем действуем по подробному промпту как
по спеке; недостающие детали (CSS-селекторы коллекторов, точные пороги скоринга,
раскладка админки) проектируются здесь и в коде.

## Решения

1. **Схема — эволюция, не новая таблица.** `radar_companies` уже создана
   миграцией 0005 (поля `class`, `directory`, `has_site`, …). Миграция 0006
   расширяет её (`grade`, `signals`, `web_status`, `website`, `email`,
   `social_links`, `verified_at`, `discarded`, `discard_reason`, `source`),
   добавляет `UNIQUE(phone)` (таблица пустая — безопасно) и создаёт `radar_runs`.
   `class`/`directory` остаются для обратной совместимости (store пишет и `grade`,
   и `class`; и `source`, и `directory`).

2. **Скоринг детерминирован и чист.** Сеть (доступность сайта, CTA, возраст
   домена) собирается в отдельном async-шаге `enrich`, безопасном к таймаутам;
   `scoreCompany(signals)` — чистая функция сигналы→оценка. Так гарантируется
   «2 прогона = одинаковый результат». A = ≥3 сигналов и адаптивность, B = 1–2,
   C = базовый. Грейд никогда не NULL.

3. **Исходящий rate-limit — свой.** `src/lib/rate-limit.ts` (Upstash) защищает
   ВХОДЯЩИЕ публичные роуты. Коллекторам нужен ИСХОДЯЩИЙ троттлинг (задержки между
   запросами к каталогам) — простой in-process лимитер в `collectors/base.ts`.

4. **robots.txt уважается.** Base-коллектор перед сканированием читает
   `/robots.txt` источника и пропускает запрещённые пути; при `Disallow: /` для
   `*` источник помечается как заблокированный и не сканируется.

5. **Достижимость из песочницы.** `pc.uz`, `gigal.uz`, `yellowpages.uz`,
   `olx.uz` доступны; `2gis.uz` → 403 (бот-защита на IP датацентра). Живой сбор с
   2gis, вероятно, придётся запускать с машины владельца/резидентного IP —
   коллектор реализуется, но помечается как «может требовать локального запуска».

6. **Рантайм CLI.** Node 25 исполняет TS нативно (strip-types). CLI —
   `node scripts/radar/cli.ts`; radar-модули используют относительные импорты и
   собственный Supabase-admin-клиент (без `server-only`), чтобы работать вне Next.

## Последствия

Идемпотентный upsert по `phone`; мягкое удаление через `discarded`. Пайплайн
безопасен к повторным прогонам. Сбор персональных бизнес-контактов из публичных
каталогов — легальный B2B lead-gen; robots.txt и rate-limit соблюдаются.
