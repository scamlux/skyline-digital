# ADR 0011 — «Сводка в Telegram» в демо-кабинетах: реальный бот

Дата: 2026-11-10 · Статус: принято · Связано: ADR 0009 (шаблоны сайтов)

## Контекст

В кабинетах четырёх шаблонов (`/sites/<ниша>/admin`) блок «Сводка в Telegram» только показывал текст-образец.
Демо-данные живут в localStorage посетителя, серверных данных нет. Нужно, чтобы владелец бизнеса мог нажать
кнопку и получить такую сводку настоящим сообщением в Telegram.

## Варианты

1. Просить у посетителя Telegram-аккаунт/чат и хранить его на сервере — хранение персональных данных, больше трения.
2. Deep link в бота: цифры едут в `t.me/<бот>?start=<payload>`, вебхук отвечает в тот же чат и ничего не хранит.
3. Отправка с клиента напрямую в Bot API — токен утёк бы в бандл.

## Решение

Вариант 2. Отдельный демо-бот (`TELEGRAM_DIGEST_BOT_TOKEN`), не бот заявок. Нагрузка — компактная строка
версии 1 (`kit/digest-payload.ts`): заголовок `1<шаблон><язык><стиль><период>` и числа в base36 через «-»;
длина с максимальными числами ≤ 64 символов (лимит `start`). Вебхук `POST /api/telegram/digest`: сверка
`X-Telegram-Bot-Api-Secret-Token` через timing-safe сравнение, Zod на апдейт и на числа, лимит 5 ответов за 10 минут
на чат (`src/lib/rate-limit.ts`), всегда 200 после обработки. Текст сводки собирается из тех же строк
`admin-ui.ts`, что и превью кабинета (`src/lib/telegram-digest/format.ts`).

Шаблоны остаются переносимыми: кнопка и кодирование лежат в `kit/`, имя бота приходит в кабинет пропом
`digestBot` через `TemplateDef.renderAdmin`. Без `NEXT_PUBLIC_TELEGRAM_DIGEST_BOT` (экспортированный сайт клиента,
неналаженный деплой) кабинет показывает только превью без кнопки.

## Последствия

- Нагрузку можно подделать: сервер ничему в ней не верит сверх границ и всё равно подписывает сообщение как демо.
- Индексы позиций (услуга, мастер, напиток) — порядок в каталоге шаблона; перестановка каталога меняет смысл
  уже розданных ссылок, поэтому при смене схемы полей поднимаем версию формата.
- Ничего не хранится: chat id существует только в ключе лимитера на время окна.
- Вебхук ставится вручную скриптом `scripts/telegram/set-digest-webhook.mjs` (токен и секрет только из env).
