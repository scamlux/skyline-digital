# 0003 — AI-провайдер: остаёмся на OpenAI вместо Anthropic

**Статус:** accepted · **Дата:** 2026-08-31

## Контекст
§2/§8 ТЗ называют Anthropic (`claude-sonnet-4-6`) провайдером для генерации текста КП. Реализация с самого начала работает на OpenAI (`gpt-4o-mini`, structured outputs) — расхождение зафиксировано в `docs/AUDIT.md` и висело в `TODO.md` как открытый разрыв, требующий решения владельца.

Решение нужно было принять до запуска платного трафика: менять провайдера после того, как через калькулятор пойдут живые лиды, дороже.

## Варианты
1. **Мигрировать на Anthropic.** Буква ТЗ соблюдена. Стоит переписывания клиента (`src/lib/ai/client.ts`), схемы (`src/lib/ai/schema.ts`) под tool-use вместо structured outputs, повторной калибровки промпта на трёх языках и нового прогона качества КП.
2. **Остаться на OpenAI, зафиксировать отход в ADR.** ТЗ §2 допускает обоснованные отклонения через ADR — тот же механизм уже применён для PDF-движка (ADR-0001).

## Решение
Вариант 2. Остаёмся на OpenAI.

Обоснование:
- **AI не решает цену.** Ключевой инвариант проекта — детерминированный движок `src/lib/pricing` единственный источник истины по стоимости и срокам; AI-слой только объясняет и форматирует, и это принудительно проверяется в `client.ts`. Значит выбор провайдера не влияет на корректность коммерческой части — он влияет только на качество формулировок.
- **Structured outputs уже работают** на трёх языках и дают стабильный JSON под схему КП. Миграция — это регрессионный риск в единственном месте, которое видит клиент, ради соответствия букве, а не результату.
- **Приоритет момента** — запуск привлечения клиентов (`docs/GROWTH-PLAN.md`). Неделя на смену провайдера не приносит ни одного лида.

## Последствия
- ➕ Пункт закрыт, `TODO.md` чище, ресурс уходит на `/audit` и лидогенерацию.
- ➕ Ключ и модель настраиваются через `OPENAI_API_KEY` / `OPENAI_MODEL` — смена модели не требует правок кода.
- ➖ Формальное расхождение с §2/§8 ТЗ остаётся; при передаче проекта третьей стороне это надо озвучивать явно.
- ➖ Зависимость от одного вендора. Митигация: `src/lib/ai/client.ts` изолирует провайдера за одной функцией — если понадобится, замена локализована в одном файле.

## Пересмотреть, если
Качество текста КП начнёт вызывать нарекания клиентов, либо появится требование заказчика на конкретного вендора.
