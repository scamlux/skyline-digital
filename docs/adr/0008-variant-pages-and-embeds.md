# ADR 0008 — Страницы вариантов: общий диспетчер и перекраска старых интерактивных блоков

Дата: 2026-10-26 · Статус: принято · Связано: ADR 0007 (переключатель версий)

## Контекст

После главной (фаза 1) все остальные страницы — проекты, услуги, «О нас», контакты,
аудит, калькулятор, смета — нужно было показать в вариантах Studio и «Референс», не
трогая старый дизайн (он сверяется с продом: видимый текст, CSS, шрифты 1:1). Часть
страниц — это крупные клиентские компоненты со своей логикой: форма заявки
(`ContactForm`), аудит (`AuditRunner`), мастер калькулятора (`Wizard`), смета с PDF.

## Варианты

1. Копия каждой страницы и каждого интерактивного компонента под каждый вариант.
2. Общий диспетчер страниц + новые серверные «тела» для статичных страниц; интерактивные
   блоки — те же компоненты, перекрашенные CSS-слоем в токены варианта.
3. Переписать интерактивные компоненты на CSS-переменные во всех версиях сразу.

## Решение

Вариант 2. `withVariants({ old, studio, ref })` — диспетчер, как у главной: читает
`site_version`, рендерит тело варианта в его каркасе, нет варианта → страница целиком
в `old`. `generateMetadata`/`generateStaticParams`/`revalidate` остаются в `page.tsx`,
SSG сохраняется. Данные деталок (проект, услуга) вынесены в `lib/site/*-page.ts`, чтобы
варианты показывали ровно те же цифры и тексты, что старые страницы.

Интерактивные блоки оборачиваются в `.v-embed`: слой в `public/variants/shared.css`
переопределяет утилиты старой палитры (Tailwind `@theme inline` зашивает hex, поэтому
переопределяем классы, а не переменные) на токены `--e-*`, которые задаёт каждый вариант.
Тело сметы вынесено в `EstimateView` с `wrapper` (`main` в старом дизайне, `div` в
вариантах — их каркас уже рендерит `<main>`). Вариант 3 отклонён: он меняет старый дизайн.

## Последствия

- Логика форм, расчёта, антиспама и PDF одна на все версии — нет расхождений в ценах.
- Раскладка внутри форм/мастера/сметы — старая; полная перерисовка под вариант возможна
  позже без смены архитектуры (новый компонент-тело в `withVariants`).
- Новые утилиты старой палитры в этих компонентах нужно добавлять в `.v-embed`, иначе они
  останутся в цветах старого дизайна внутри варианта.
