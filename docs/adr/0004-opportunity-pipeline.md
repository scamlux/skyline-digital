# ADR 0004 — Конвейер заказов: полуавтомат «система ищет и готовит — владелец решает»

_2026-10-09_

## Контекст

Владелец хочет конвейер: профили на площадках ведутся сами, заказы находятся сами, ему приходит только проект к реализации. Исследование каналов (`docs/business/LEAD-CHANNELS-2026-10.md`) показало три ограничения, которые полный автопилот не обходит:

- **Правила площадок.** Upwork запрещает ботов и автоматические отклики (бан аккаунта). Публичные RSS Upwork закрыты с 2024 года, API поиска заказов доступен только партнёрам. LinkedIn запрещает автоматизацию. Reddit и HN банят за автопостинг.
- **Тендеры** требуют подписи, деклараций и ответственности за содержание. Подать EOI «от имени» студии без человека нельзя.
- **Деньги и репутация.** Отклик от бота с выдуманным опытом стоит дороже упущенного заказа. Правило `brain.md` «ни одной цифры вне движка» действует и для продаж.

## Варианты

1. **Полный автопилот:** боты логинятся на биржи, сами откликаются и постят. Нарушает правила площадок, первый бан обнуляет профиль. Отклонено.
2. **Подписка на чужой агрегатор** (например, открытая база ta-tenders). Хороший охват тендеров, но лицензии нет, формат не наш, а зависимость от чужого репозитория — точка отказа. Не берём в ядро. Можно подключить позже как RSS, если появится фид.
3. **Полуавтомат.** Система сама собирает из открытых источников и писем-оповещений, отсеивает, оценивает, считает цену движком и пишет черновик отклика. Владельцу приходит карточка в Telegram с кнопками. Отправка остаётся за человеком: одна копипаста. Площадки без API ведутся напоминаниями с готовым текстом.

## Решение

Вариант 3. Модуль `src/lib/pipeline/`:

- **Сборщики** (только официальные или публичные источники):
  - World Bank Procurement API;
  - Reddit JSON (`[Hiring]`);
  - публичные Telegram-каналы через `t.me/s/`;
  - любые RSS/Atom-ленты;
  - Freelancehunt API (личный токен).
- **Универсальный вход** `/api/pipeline/ingest`. Сюда приходит любое письмо-оповещение (Upwork job alerts, UNGM Tender Alert, рассылки Всемирного банка, Workspace) через Gmail → Apps Script. ИИ режет письмо на отдельные заказы. Так покрываются площадки без API, и их правила не нарушаются: мы читаем свою почту.
- **Пересылка боту.** Заказ из закрытого чата владелец пересылает боту, и тот сразу идёт в конвейер, без отсева.
- **Этапы обработки:**
  1. Префильтр (бесплатный, словари ru/uz/en, дедлайн, бюджет, вакансии в штат).
  2. ИИ-оценка: тип проекта и ключи только из каталога движка, без денег.
  3. Цена — `computePricing`.
  4. Черновик отклика; `enforceEngineNumbers` вычищает любые суммы, кроме вилки движка.
  5. Карточка с кнопками.
- **Решения владельца** (`applyAction`) одинаковы из Telegram и `/admin/pipeline`. «Выиграли» создаёт заявку в `leads` (`source = pipeline:<источник>`), дальше обычный путь: КП, договор.
- **Рутины профилей:** HN раз в месяц, r/forhire раз в неделю, обновление Upwork/Contra, сбор отзывов, квартальная проверка тендерных документов. Плюс недельная сводка по пятницам.
- **Крон.** Конвейер едет на существующем 15-минутном тикере контента (cron-job.org) и сам троттлится до `PIPELINE_INTERVAL_MIN`. Отдельный крон не нужен, но есть и `/api/cron/pipeline`.
- **ИИ** — текущий клиент проекта (OpenAI, как у калькулятора), с тем же журналом `ai_calls` и гардами. Переход на Anthropic (§8) — общая открытая задача `TODO.md`, конвейер переедет вместе с остальными точками ИИ. Без ключа конвейер работает на эвристике и шаблонах.

## Последствия

- Владелец тратит время только на решение «да/нет» и одну отправку. Поиск, отбор, оценка и текст — на системе.
- Отправка не автоматизирована сознательно. Если площадка даст официальный API подачи, его можно добавить в `applyAction("go")`, не меняя остальное.
- **Форматы источников не проверены живьём:** сеть среды разработки закрыта. Парсеры написаны по документированным форматам, терпимы к пропускам и покрыты тестами на образцах. Сломанный источник видно в `pipeline_runs.errors`, на `/admin/pipeline` и в недельной сводке, конвейер при этом не падает.
- Reddit часто режет запросы с IP дата-центров (Vercel). Этот источник best-effort.
- Миграция `0013_pipeline.sql` применяется вручную, как прежние.
