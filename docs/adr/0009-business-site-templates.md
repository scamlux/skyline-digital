# ADR 0009 — Шаблоны сайтов для бизнеса по подписке (/sites)

Дата: 2026-10-28 · Статус: принято · Связано: `docs/business/NICHE-SITES-RESEARCH-2026-10.md`, ADR 0007/0008

## Контекст

Продукт: отраслевой сайт (ресторан, клиника, салон…) за **50 $/мес, один тариф**
(решение владельца). Приоритет — дизайн, удобство, понятность. Владелец хочет:
1) показывать живые демо на нашем домене (в URL, без отдельных доменов);
2) при необходимости отдавать такой сайт клиенту на бесплатный хостинг, на его аккаунт,
и чтобы всё работало так же — вся подписка остаётся чистой прибылью.

## Варианты

1. Мультитенантная платформа (одна БД, все сайты клиентов крутятся у нас).
2. Шаблоны как самодостаточные модули: данные + тексты + CSS внутри модуля, без зависимости
   от нашей админки/БД; демо — маршруты на нашем сайте; экспорт — отдельным шагом.
3. Отдельный репозиторий/проект на каждый шаблон.

## Решение

Вариант 2. Шаблон = папка `src/site-templates/<ниша>/`: `data.ts` (контент, 3 языка), `ui.ts`
(тексты интерфейса, 3 языка), серверный компонент `<Ниша>Site`, минимальные клиентские
острова (`client.tsx`), стили `public/templates/<ниша>.css` с шрифтами `public/templates/fonts/`.
Запись в `src/site-templates/registry.tsx` — и витрина `/sites`, и маршруты
`/[locale]/sites/<ниша>/<стиль>` подхватывают её сами. Два стиля — одна разметка, разные
токены (`data-style="a|b"`). Демо-слой (плашка «Демо», переключатель стилей, «Заказать»)
живёт в маршруте и в шаблон не входит.

Переносимость:
- шаблон не импортирует `next-intl`, Supabase, админку и компоненты сайта студии;
- CSS не импортируется, а подключается через `<link>` из `public/` (так же, как варианты
  сайта, ADR 0007: импортированный `.css` Turbopack добавляет во все маршруты);
- бронь по умолчанию в режиме `telegram` открывает чат владельца с готовым текстом —
  работает без сервера; режим `demo` показывает подтверждение;
- «открыто сейчас» считается в браузере по времени Ташкента (UTC+5).

Экспорт на хостинг клиента (статический Next-проект из одного шаблона) — следующий шаг;
архитектура его не блокирует, но скрипт пока не написан.

## Последствия

- Каждая новая ниша — 4 файла + CSS, общий каркас не копируется.
- Демо и боевые сайты клиентов используют один и тот же код — исправления дизайна
  получают все.
- Правки владельцем (меню, цены, часы) в этой версии — через данные; админка «на месте»
  и дашборд владельца — отдельные задачи (см. TODO).
- Фото блюд не обязательны: меню остаётся чисто типографским, `image` — необязательное поле.
- Демо-бизнес вымышленный (Dasturxon): адрес, телефон, цены и тексты — не чужой бренд.
