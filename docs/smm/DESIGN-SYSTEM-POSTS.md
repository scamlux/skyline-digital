## 1. Принцип, на котором всё держится

Твой разбор нашёл главное: у githubradar и frontend_champs **себестоимость поста — одна строка текста**. Один шаблон, меняется одно слово. Это и есть то, что делает faceless-подход выносимым в одиночку.

Отсюда правило системы:

> **Пост — это данные, а не макет.** Дизайнер не открывается. Меняется JSON, шаблон остаётся.

Второе правило — из того же разбора, но обратное по знаку. У обоих медиа-аккаунтов **ноль комментариев**, потому что они ничего не спрашивают. У aziz_udevs один пост с «напишите 7» дал 140 комментариев против 3 у обычного ролика. Значит:

> **Шаблон берём у медиа, цель — у личного бренда.** Дизайн конвейерный, но каждый пост заканчивается разговором.

## 2. Токены

Палитра — та же, что на сайте. Ничего нового не вводим.

| Токен | Значение | Где |
| --- | --- | --- |
| `night` | `#1A2238` | фон тёмных шаблонов, текст на светлых |
| `apricot` | `#FFAE5C` | ключевое слово, уголковые скобки, цифры |
| `afterglow` | `#E8517C` | одно выделенное слово на светлом, надзаголовки |
| `paper` | `#F4F6FA` | фон светлого шаблона Ш3 |
| `paper2` | `#F3EAD8` | тёплая «бумага» Ш2 — новый токен, добавлен для контраста в сетке |
| `line` / `lineNight` | `#D5DBE7` / `#2E3855` | разделители |

**Шрифты:** Unbounded (заголовки и цифры) · Golos Text (текст) · JetBrains Mono (служебные строки, цены, код).

**Холсты:** лента 1080×1350 · квадрат 1080×1080 · сторис 1080×1920 · документ LinkedIn 1080×1350.

**Уголковые скобки** — приём uic.group. Абрикосовые, 3 px, верхний левый и нижний правый угол. Включаются полем `"frame": true`. Стоят ноль, читаются как «дорогая студия». Ставим почти везде, кроме Ш3 — там рамку заменяет интерфейсная разметка.

## 3. Пять шаблонов

### Ш1 · «Одно слово» — `"type": "word"`

Взято у **githubradar** (68,7K). Три строки по центру на ночном фоне, меняется одно слово из трёх. Фон — диагональные штрихи 12%, расставлены детерминированно, чтобы один и тот же слайд рендерился одинаково.

```json
{ "type": "word", "tone": "dark", "frame": true,
  "eyebrow": "Цена вопроса",
  "line1": "Сколько стоит", "line2": "Лендинг", "line3": "в Ташкенте" }
```

Строка 2 — абрикосовая, Unbounded 120 px, ЗАГЛАВНЫЕ. Это и есть переменная. **Держи её в одном слове:** два слова ломают композицию.

**Для чего:** Радар, Цена вопроса, любой пост-заявление. Себестоимость — одна строка.

### Ш2 · «Бумага» — `"tone": "paper"` на обычном `cover`

Взято у **githubradar**, контрастный стиль. Тёплый кремовый `#F3EAD8` с точечной сеткой шагом 24 px. Нужен ровно затем, чтобы сетка профиля не превращалась в чёрное пятно.

```json
{ "type": "cover", "tone": "paper", "frame": true,
  "eyebrow": "Радар · выпуск 1", "title": "…", "subtitle": "…", "swipe": "листай →" }
```

**Ограничение, проверенное рендером:** заголовок до шести слов. Длиннее — пять строк на весь слайд, и подзаголовок начинает драться с точечной сеткой.

### Ш3 · «Псевдо-интерфейс» — `"type": "ui"`

Взято у **frontend_champs** (190K). Самый быстрый в производстве и самый универсальный. Верхняя полоса — аватар, имя, `@skylinedigital.uz`. Центр — хук, слово в `*звёздочках*` красится в afterglow. Ниже — крупный знак. Низ — ряд действий.

```json
{ "type": "ui", "tone": "light",
  "eyebrow": "Вайбкодинг",
  "title": "Собрал рабочий прототип *за вечер*",
  "glyph": "1 / 5", "subtitle": "…",
  "actions": ["нравится", "сохранить", "отправить"] }
```

Две правки против оригинала, обе по итогам рендера:

- **Иконки нарисованы вектором**, а не рамками из CSS. Рамочные фигуры на холсте 1080 px читаются как случайные квадраты — проверено, выглядело плохо.
- **Ряд действий без счётчиков.** У frontend_champs там фейковые цифры лайков. Мы ставим только иконки и подписи: это призыв к действию, а не имитация чужой статистики. Разница принципиальная — выдуманные счётчики это подделка доказательства.
- Глиф приглушён до цвета `line`: в первой версии он перебивал хук, а хук здесь главный.

### Ш4 · «Плашка-хук поверх кадра» — `"type": "plate"`

Взято у **aziz_udevs** и **PROWEB**. Белая плашка с абрикосовой обводкой 3 px в верхней трети — там, где её видно в мелкой сетке профиля.

```json
{ "type": "plate", "tone": "dark", "frame": true,
  "image": "/public/projects/example.jpg",
  "hook": "5 ошибок, из-за которых сайт теряет заказы",
  "ask": "Разбор сайта кофейни в Ташкенте. Обезличенно.",
  "note": "Четыре из пяти чинятся за день.",
  "swipe": "листай →" }
```

**Работает лучше всего со скриншотом разбираемого сайта.** Скриншот обязательно обезличен: логотип и домен замазаны. Если снимка нет, `image` опускается — кадр заменяется фирменной штриховкой, и слайд остаётся собранным. Это добавлено после первого рендера: без снимка нижняя половина читалась как обрыв вёрстки.

### Ш5 · «Кейс-борд» — карусель, а не один слайд

Взято у **uic.group** — у аккаунта с лучшей вовлечённостью из семи (5,71%). Структура шести слайдов:

| Слайд | Тип | Что на нём |
| --- | --- | --- |
| 1 | `cover` или `plate` | клиент и задача одной строкой |
| 2 | `case` | скриншот проекта |
| 3 | `points` | что нужно было решить |
| 4 | `palette` | цвета и типографика проекта |
| 5 | `compare` или `stat` | результат цифрой |
| 6 | `cta` | призыв |

Новый тип `palette` — плитки цветов с подписями хексов:

```json
{ "type": "palette", "tone": "light", "frame": true,
  "colors": ["#1A2238", "#FFAE5C", "#E8517C"],
  "text": "…", "tags": ["Unbounded", "Golos Text"] }
```

## 4. Ритм сетки профиля

Правило чередования по дням: **тёмный → светлый → тёмный → светлый**. Сетка профиля читается как шахматная доска — именно этим githubradar держит визуальный ритм при одном шаблоне.

| День | Рубрика | Шаблон | Тон |
| --- | --- | --- | --- |
| пн | Разбор | Ш4 плашка | тёмный |
| ср | Радар | Ш2 бумага | светлый |
| пт | Цена вопроса / Кейс | Ш1 слово / Ш5 борд | тёмный |
| вс | Вайбкодинг | Ш3 интерфейс | светлый |

Закреплённая тройка наверху профиля — **кто мы → что делаем → как начать**. Обновляется раз в квартал. Не мозаика из двенадцати плиток: она ломается первым же новым постом, это ловушка uicgroup.uz.

## 5. Тексты

### Хук на обложке — четыре конструкции

| Конструкция | Пример |
| --- | --- |
| Число + категория | «5 ошибок на сайте, из-за которых вам не пишут» |
| Обязанность | «Это должен знать любой, кто заказывает сайт» |
| Превосходная степень | «Самые быстрые сайты Ташкента — как их делают» |
| Вопрос-провокация | «Сайт за $450 — это вообще возможно?» |

### Скелет подписи

```
[Хук одной строкой — то же обещание, что на обложке]

[2–3 предложения пользы: кому это, зачем сейчас]

[Конкретика списком: реальные названия, цифры, шаги]

[Строка-мораль: что на самом деле важно]

[ВОПРОС читателю]
[Призыв прокомментировать]

Сохраните, чтобы не искать. Перешлите тому, кто …

Skyline Digital — сайты и веб-приложения в Ташкенте.
```

Вопрос и призыв прокомментировать — не украшение: по данным Metricool за январь–февраль 2026 вопрос даёт +36,7% комментариев, прямой призыв — **+202,8%**.

### Комментарий-ключ

Механика aziz_udevs: пост-карусель с «напишите 7 в комментариях» дал 449 лайков, **140 комментариев** и 46 репостов против 98/3/— у обычного ролика того же аккаунта.

Правила, как её ставить:

1. Обещай **конкретный артефакт**, а не «инфу»: чек-лист, шаблон ТЗ, разбор сайта, смету.
2. Слово-ключ короткое и легко печатается: `РАДАР`, `КЕЙС`, `ЧЕК`, `ШАБЛОН`.
3. Отвечай в директ **в течение часа** — пока Instagram считает диалог активным.
4. В ответе: артефакт **плюс один уточняющий вопрос**. Вопрос превращает выдачу в разговор.
5. Не чаще чем на каждый третий-четвёртый пост, иначе перестают реагировать.

В остальных постах — обычный вопрос без ключа. Разница: ключ просит действие, вопрос просит мнение.

## 6. Один спорный пункт: хэштеги

**В твоём разборе они есть, в моих данных они вредят.** Разбираю честно, решение за тобой.

| За хэштеги | Против |
| --- | --- |
| githubradar ставит 4, frontend_champs ровно 5 | Metricool, 24,4 млн постов, январь–февраль 2026: посты с хэштегами получают **−31,70% просмотров и −33,89% взаимодействий** относительно средней по платформе |
| Оба — крупные аккаунты с большим охватом | Оба — **медиа-аккаунты с другой экономикой**: им нужен охват на продажу рекламы, тебе нужны заявки. У обоих при этом ноль комментариев |

**Моя рекомендация: ставим ноль хэштегов.** Причина не только в цифре Metricool — она корреляционная, аккаунты, гоняющиеся за охватом, чаще их ставят. Причина в том, что хэштеги приводят случайную аудиторию, а тебе нужны триста человек, которые заказывают сайты, а не тридцать тысяч, которые смотрят.

Во всех четырёх постах первой недели `"hashtags": []`. **Это дешёвый тест:** если через восемь постов охват не сдвинется, добавляем по 4 штуки в следующие восемь и сравниваем медианы. Поле в спецификации есть, менять — одна строка.

## 7. Промпты для фонов

Кириллицу генераторы ломают. Поэтому промптом делается **только фон и графика**, текст накладывается фабрикой. Промпты из твоего приложения годятся как есть — с одной поправкой: убирай из них все строки с надписями.

Для Ш4 (единственный шаблон, которому нужна картинка):

```
Instagram post 1080x1350. Background: clean photo of a laptop screen showing a generic
website layout, slightly desaturated, dark navy colour grading. No text, no logos,
no readable interface labels. Realistic but clean, no people, no faces.
```

Для Ш5, слайд с мокапом:

```
Instagram carousel slide 1080x1350. Studio product shot on a deep navy #1A2238 seamless
background. Centered: a modern smartphone mockup displaying a clean website homepage
with an apricot accent colour. Soft directional light from the top left.
Premium agency case study aesthetic, minimal, no text overlays.
```

Ш1, Ш2 и Ш3 генератор не требуют вообще — они собираются фабрикой целиком.
