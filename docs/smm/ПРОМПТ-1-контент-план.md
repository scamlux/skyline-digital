# ЗАДАЧА

Собери контент-план Instagram на следующий месяц для веб-студии Skyline Digital (Ташкент). Результат — один файл `docs/smm/content-plan-<год>-<месяц>.json` плюс читаемая версия `КОНТЕНТ-ПЛАН.md`.

Образец структуры и уровня проработки — `docs/smm/content-plan-2026-09.json`. Повтори его схему поле в поле.

## 1. СНАЧАЛА ПРОЧИТАЙ

| Файл | Зачем |
| --- | --- |
| `docs/smm/content-plan-<прошлый месяц>.json` | схема и что уже выходило — не повторяться |
| `docs/smm/brain.md` | цены, тон, стоп-лист, обязательные правила площадок |
| `docs/smm/FORMATS.md` | правило длины: сколько слайдов и почему |
| `docs/smm/SMM-ANALYSIS-2026-09.md` | разбор рынка, конкурентов и алгоритмов |
| `docs/smm/state.json` | что сработало по факту: медианы по форматам, kill-list |
| `src/lib/pricing/` | **цены брать только отсюда**, не из памяти |

**Если в `state.json` есть данные прошлого месяца — план строится на них, а не на общих соображениях.** Формат с медианой выше общей получает дополнительный слот. Формат из kill-list не планируется вовсе.

## 2. РИТМ

Четыре поста в неделю, рубрики закреплены за днями:

| День | Рубрика | Что это |
| --- | --- | --- |
| пн | **Разбор** | публичный разбор чужого сайта, обезличенно. Флагман: этого не делает ни один конкурент в Ташкенте |
| ср | **Радар** | подборка готовых решений. Самый сохраняемый тип |
| пт | **Цена вопроса** или **Кейс**, через неделю | прозрачность и доказательства |
| вс | **Вайбкодинг** | второй стиль, лёгкий, без корпоративности |

Тон обложек чередуется строго: **пн тёмный · ср светлый · пт тёмный · вс светлый.**

Комментарий-ключ ставится **ровно на каждый третий-четвёртый пост** — четыре ключа на шестнадцать постов. Чаще — аудитория перестаёт реагировать.

## 3. ПРАВИЛО ДЛИНЫ

> Слайдов = обложка + число самостоятельных мыслей + призыв.

Не подгонять под пять. Мысль, которую можно выкинуть без потери, — не мысль, и слайд под неё отнимает охват: наполнитель обрывает пролистывание, а Instagram переподаёт карусель с другого слайда только тем, кто до него долистал.

Ориентир по разбросу за месяц: одна одиночная картинка, одна-две коротких карусели на 3–4, основная масса на 5, одна длинная на 7–9 под артефакт, который сохраняют.

Одиночная картинка — **не чаще одной в месяц**: за год одиночные фото потеряли 22% охвата и 46% вовлечённости. Ставить только туда, где картинка и есть весь смысл поста, а детали живут в подписи.

## 4. ЧТО ЗАПОЛНИТЬ ПО КАЖДОМУ ПОСТУ

```
id · date · day · time_instagram · time_telegram · rubric · title
format · slides_count · template · tone_cover · comment_key · platforms
status: ready | draft | blocked
slides: [ полные тексты всех слайдов ]
caption_instagram · caption_telegram
```

Тексты слайдов пишутся целиком, а не тезисами. Подпись строится по скелету:

```
[Хук одной строкой — то же обещание, что на обложке]
[2–3 предложения пользы: кому это и зачем сейчас]
[Конкретика списком: реальные названия, цифры, шаги]
[Строка-мораль: что на самом деле важно]
[ВОПРОС читателю]
[Призыв прокомментировать]
Сохраните, чтобы … Перешлите тому, кто …
Skyline Digital — сайты и веб-приложения в Ташкенте.
```

## 5. ЧЕГО НЕЛЬЗЯ

1. **Ни одной выдуманной цифры.** Цены только из `src/lib/pricing/`: сайты от $1 000 · веб-приложения от $2 080 · ИИ от $1 680 · автоматизация от $1 130 · мобильные от $2 590 · UI/UX от $840. Всё остальное опровергается калькулятором на сайте за один клик.
2. **Хэштегов ноль.** Минус 31,7% просмотров.
3. **Разбор пишется только после реального аудита живого сайта.** Придумать правдоподобные ошибки и выдать за разбор — самая дорогая ошибка в этом плане: владелец узнает свой сайт и увидит, что написанное не про него. Если аудит не проведён — ставь `status: draft` и в `blocker` пиши, что нужно проверить.
4. **Разбор всегда обезличен:** без названия, домена и логотипа. Локальный малый бизнес по имени не разбираем никогда — рынок маленький, это будущий клиент.
5. **«До/после» без числа не публикуется.** Нет доступа к аналитике клиента — меряем то, что можем сами: скорость, число шагов до цели, количество полей в форме.
6. **В каждом посте вопрос и призыв прокомментировать.** Плюс 36,7% и плюс 202,8% комментариев соответственно.
7. **Последний слайд проектируется под пересылку** — это сигнал ранжирования номер два.

## 6. ЧТО ВЕРНУТЬ

Два файла плюс короткий отчёт: сколько постов и кадров, разбивка по форматам, список ключей, что в статусе `draft` и `blocked` и почему.

Отдельно назови **темы, которые ты отверг** и по какой причине — это дороже, чем список принятых.
