## 4. ПОРЯДОК СБОРКИ

Работай **шагами по одному посту**, не пытайся собрать всё одним вызовом. После каждого поста делай `screenshot()` первого слайда и смотри на результат. Возвращай ID созданных узлов из каждого вызова.

1. Прочитать JSON-файлы контента
2. Собрать страницу `00` — профиль
3. Очистить страницу `01`
4. Собирать посты по одному, в порядке дат
5. Финальная проверка по разделу 8

**Раскладка на холсте страницы `01`:** каждый пост — горизонтальный ряд слайдов слева направо, шаг по X = 1150. Ряды сверху вниз по датам, шаг по Y = 1610. Над каждым рядом текстовая подпись `<дата> · <день> · <рубрика>` (JetBrains Mono Bold 44, трекинг 8%, цвет night) на 140 px выше ряда.

**Имя фрейма:** `<дата> · <день> · <рубрика> · <N>/<всего>`. Например `07 сен · пн · Разбор · 1/5`.

## 5. ТИПЫ СЛАЙДОВ

Все размеры в пикселях для холста 1080. Все текстовые блоки — `textAutoResize = "HEIGHT"` с явной шириной, потом `layoutSizingHorizontal = "FILL"` **после** добавления в родителя.

### `cover` — обложка
Надзаголовок (Mono Bold 26, трекинг 20%, акцент) → заголовок `title` (Unbounded Bold 85, трекинг −3%, интерлиньяж 100%) → подзаголовок `sub` (Golos Regular 34, интерлиньяж 145%, вторичный) → подвал.

### `word` — одно слово, только тёмный
Три строки по центру: `l1` (Mono Bold 35, трекинг 20%, on-night-soft) → `l2` (Unbounded Bold 116, трекинг −3.5%, интерлиньяж 94%, **apricot**) → `l3` (Unbounded SemiBold 56, трекинг −2%, on-night). Обязательны штрихи.

### `points` — пронумерованный список
Надзаголовок → `title` (Unbounded SemiBold 58) → список. Каждый пункт: горизонтальный авто-лейаут, отступ 26; слева номер `n` (Mono Bold 28, трекинг 6%, ширина 64, акцент), справа вертикальный блок — `t` (Golos SemiBold 34, интерлиньяж 125%) и `d` (Golos Regular 28, интерлиньяж 142%, вторичный). Между пунктами 30.

### `compare` — было и стало
Надзаголовок → `title` → два блока рядом, отступ 24, оба FILL. Левый: фон white или night-soft. Правый: фон акцента с прозрачностью 16%, обводка акцентом 2. В каждом: `cap` (Mono Bold 22, трекинг 14%) → `big` (Unbounded Bold 64, трекинг −2%) → `sub` (Golos Regular 24, интерлиньяж 140%). Радиус 18, паддинг 30/32. Ниже — `note` (Golos Regular 28, вторичный).

### `prices` — таблица
Надзаголовок → `title` (Unbounded SemiBold 54) → строки. Каждая: горизонтальный лейаут SPACE_BETWEEN, паддинг сверху и снизу 24; слева `what` (Golos SemiBold 32), справа `val` (Unbounded Bold 40, трекинг −1). Между строками линия 2 px, кроме последней. **Последняя строка выделяется:** текст основным цветом, значение акцентом. Ниже — `note`.

### `stat` — крупная цифра
Надзаголовок → горизонтальный блок HUG с выравниванием по нижнему краю: `value` (Unbounded Bold 190, или 96 если длиннее четырёх знаков, акцент) и `unit` (Unbounded SemiBold 52, вторичный), отступ 20 — **оба HUG, иначе единица оторвётся от числа** → `title` (Unbounded SemiBold 58) → `note`.

### `take` — крупное мнение
Надзаголовок → кавычка `“` (Unbounded Bold 120, акцент) → `text` (Unbounded SemiBold 60, трекинг −2%, интерлиньяж 114%). Слово в `*звёздочках*` красится акцентом через `setRangeFills`, сами звёздочки из текста убрать → `note`.

### `plate` — плашка-хук поверх кадра, только тёмный
1. Прямоугольник 1080×1350 цветом line-night, обводка apricot 50% толщиной 4, пунктир [18,14], имя слоя `СЮДА СКРИНШОТ · логотип и домен замазать`
2. Штрихи
3. Вуаль: прямоугольник 1080×1350 цветом night с прозрачностью 30%, имя `вуаль`
4. Уголки
5. Текст-маркер по центру на Y 720: `СКРИНШОТ 1080×1350 / ЛОГОТИП И ДОМЕН ЗАМАЗАТЬ`, Mono Bold 26, трекинг 12%, apricot 75%, имя слоя `УДАЛИТЬ ПОСЛЕ ВСТАВКИ СКРИНШОТА`
6. Колонка: белая плашка (радиус 24, обводка apricot 3, паддинг 44/48) с `hook` (Unbounded Bold 52, night) и `ask` (Golos Regular 30, ink-soft); под плашкой `note` (Golos Regular 32, белый) → подвал

### `case` — кадр проекта
Надзаголовок → фрейм-заглушка 900×470, радиус 16, обводка акцентом 50% толщиной 4, пунктир [18,14], имя `СЮДА ОБЛОЖКА · <значение поля image>`, внутри по центру подпись именем файла → `text` → метки `tags` капсулами (радиус 999, фон акцента 14%, обводка акцента 50%, паддинг 22/12, Mono Bold 22) → подвал.

### `palette` — цвета проекта
Надзаголовок → `title` → ряд плиток из `colors`: вертикальный лейаут, паддинг сверху 110 снизу 18, радиус 8, заливка цветом, внизу подпись хекса (Mono Regular 20, белая на тёмном, night на светлом) → `text` → `tags` → подвал.

### `ui` — псевдо-интерфейс, без уголков и подвала
Верх: аватар-круг 66 цветом night с прямоугольником 28×10 apricot внутри; справа `Skyline Digital` (Golos SemiBold 26) и `@skylinedigital.uz` (Mono Regular 21, ink-faint); под ними линия.
Центр: надзаголовок по центру (afterglow) → `title` (Unbounded Bold 74, по центру), слово в звёздочках — afterglow → `glyph` (Unbounded Bold 132, цвет **line**, приглушённый — он опора, а не заголовок) → `sub` (Golos Regular 32, по центру).
Низ: линия, под ней ряд из трёх действий по центру, отступ 70. Каждое: SVG-иконка 34 и подпись (Mono Bold 20, трекинг 10%, ink-soft).

Иконки рисовать вектором через `createNodeFromSvg`, **не рамками из CSS** — на 1080 px рамки читаются как случайные квадраты:

```
сердце: M12 20.5 3.8 12.6a4.9 4.9 0 0 1 0-7 4.9 4.9 0 0 1 7 0l1.2 1.2 1.2-1.2a4.9 4.9 0 0 1 7 0 4.9 4.9 0 0 1 0 7Z
закладка: M5.5 3.5h13v17l-6.5-5-6.5 5Z
стрелка: M21.5 2.5 10.5 13.5M21.5 2.5l-7 19-4-8-8-4Z
```
Цвета обводки: сердце afterglow, остальные night. Подписи: НРАВИТСЯ · СОХРАНИТЬ · ОТПРАВИТЬ.
**Счётчиков лайков не рисовать.** Это призыв к действию, а не имитация чужой статистики.

### `cta` — призыв
Надзаголовок → `title` (Unbounded Bold 72) → `text` → `action` со стрелкой `→` (Mono Bold 30, акцент) → подвал.

## 8. ЧЕГО НЕЛЬЗЯ

Это не пожелания, это проверка перед сдачей.

1. **Не придумывать цифры.** Все цены только из `brain.md`: сайты от $1 000 · веб-приложения от $2 080 · ИИ от $1 680 · автоматизация от $1 130 · мобильные от $2 590 · UI/UX от $840. Любая другая цифра опровергается калькулятором на сайте за один клик.
2. **Не заполнять заглушки `ЗАМЕР`** в посте 21 сентября. Они стоят намеренно: цифры придут из движка замера.
3. **Не рисовать счётчики лайков** в шаблоне `ui`.
4. **Не добавлять хэштеги** ни в один кадр и ни в одну подпись.
5. **Не разворачивать заглушки** `СЮДА СКРИНШОТ` и `СЮДА ОБЛОЖКА` в картинки — их вставит владелец после того, как замажет логотипы.
6. **Не подгонять число слайдов под пять.** Если в JSON три слайда — собирай три.
