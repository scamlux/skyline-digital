# SHOT-LIST · что вставить в макеты

_Составлено 4 сентября 2026. Файл Figma: https://www.figma.com/design/cl4r5b5haPBRXYVNLB9u8Q — страница «01 · Посты · сентябрь»._

Шесть кадров ждут картинку и один пост ждёт данные. Ниже — по каждому: имя фрейма в Figma, имя слоя, что положить и как обрезать.

**Имена фреймов детерминированные**, поиском по слоям находятся точно: `<дата> · <день> · <рубрика> · <номер>/5`.

---

## Правило, которое не обсуждается

На всех разборах логотип и домен разбираемого сайта **замазываются до вставки**. Не после, не «потом поправим» — до.

Ташкент маленький. Владелец узнает свой сайт по кадру, и если он узнает себя в посте с заголовком «что мешает заказу» — мы потеряли клиента и получили историю в чужом чате. Обезличенный разбор читается как экспертиза, именной — как наезд.

Чем замазывать: сплошной прямоугольник цвета `#1A2238`, не блюр. Блюр восстанавливается, прямоугольник нет.

## 1. Разборы · нужен скриншот-фон

Во всех четырёх — слайд 1, шаблон Ш4 «плашка-хук». Скриншот идёт **фоном под плашку**, поэтому детали не важны: видно верхнюю треть и края.

| Фрейм в Figma | Что снять | Размер |
| --- | --- | --- |
| `07 сен · пн · Разбор · 1/5` | экран меню кофейни: сетка карточек напитков с описаниями | 1080×1350 |
| `14 сен · пн · Разбор · 1/5` | форма заявки на сайте стоматологии, целиком с полями | 1080×1350 |
| `21 сен · пн · Разбор · ЦИФРЫ ИЗ ЗАМЕРА · 1/5` | коллаж из пяти обезличенных первых экранов | 1080×1350 |
| `28 сен · пн · Разбор · запасной вариант · 1/5` | первый экран сайта автосервиса с телефоном в шапке | 1080×1350 |

**Слои внутри каждого такого фрейма:**

| Слой | Что с ним делать |
| --- | --- |
| `СЮДА СКРИНШОТ · логотип и домен замазать` | заменить заливку прямоугольника на изображение, режим **Fill**, выравнивание по верхнему краю |
| `УДАЛИТЬ ПОСЛЕ ВСТАВКИ СКРИНШОТА` | удалить этот текстовый слой |
| `вуаль` | оставить как есть — она гасит фон, чтобы плашка читалась |
| `штрих` (7 штук) | удалить, они нужны были только вместо кадра |

**Как снимать.** Ширина окна 1440, снимок первого экрана, потом обрезать до 1080×1350 по центру. Не мобильная версия: на 430 px карточки схлопываются в столбец и по кадру не видно проблемы.

## 3. Пост 21 сентября · нужны данные, а не картинка

Единственный пост, который **нельзя публиковать** до подстановки цифр. Заглушки `ЗАМЕР` стоят намеренно и заметно.

Что нужно от движка `src/lib/audit/`, по пяти доменам:

| Метрика | Куда идёт |
| --- | --- |
| Время до первого экрана, сек | слайд 2, крупная цифра — разброс между самым быстрым и самым медленным |
| Вес страницы, МБ | слайд 3, пункт про несжатые фотографии |
| Число блокирующих скриптов | слайд 3, пункт про виджеты |
| Самый медленный / самый быстрый, сек | слайд 4, сравнение |

Отрасли называем, домены — нет: «стоматология», «автосервис», «кофейня», «стройматериалы», «юридические услуги».

**Пока цифр нет — пост стоит.** Выдуманный замер в посте про замеры убивает ровно то, на чём построено всё позиционирование.

## 4. Чего не хватает раньше картинок

Три разбора из четырёх **ещё не проверены на живых сайтах**. Тексты в них — рыба: правдоподобные, но непроверенные ошибки.

| Пост | Статус |
| --- | --- |
| 7 сен · меню кофейни | ✅ аудит проведён 04.09, текст переписан по фактическим находкам |
| 14 сен · форма стоматологии | ⏳ нужен аудит: посчитать поля, проверить обязательные, что происходит после отправки |
| 21 сен · скорость пяти сайтов | ⏳ нужен замер движком |
| 28 сен · автосервис | ⏳ нужен аудит: кликается ли телефон, есть ли цены, названы ли услуги конкретно |

Порядок правильный такой: **сначала аудит, потом текст, потом кадр.** Скриншот реального сайта под выдуманными выводами — это разбор с настоящей картинкой и ложью в тексте, и это хуже, чем совсем без кадра.

## Готовое задание для Claude в Chrome

Скопировать целиком:

```
Открой файл Figma https://www.figma.com/design/cl4r5b5haPBRXYVNLB9u8Q,
страница «01 · Посты · сентябрь».

Для каждого кадра из списка:
1. Найди фрейм по имени через панель слоёв.
2. Внутри него найди слой с именем, начинающимся на «СЮДА СКРИНШОТ» или «СЮДА ОБЛОЖКА».
3. Замени его заливку на приложенное изображение, режим Fill, выравнивание по верху.
4. Удали текстовый слой «УДАЛИТЬ ПОСЛЕ ВСТАВКИ СКРИНШОТА», если он есть.
5. Удали слои с именем «штрих» внутри этого фрейма.
6. Слой «вуаль» не трогай.

Список кадров и файлов:
· 07 сен · пн · Разбор · 1/5              → кофейня-меню.png
· 14 сен · пн · Разбор · 1/5              → стоматология-форма.png
· 21 сен · пн · Разбор · ЦИФРЫ ИЗ ЗАМЕРА · 1/5 → скорость-коллаж.png
· 28 сен · пн · Разбор · запасной вариант · 1/5 → автосервис.png
· 18 сен · пт · Кейс · ключ КЕЙС · 2/5    → govbot.jpg
· 02 окт · пт · Кейс · 2/5                → tgpg.jpg

Перед вставкой проверь: на скриншотах разборов логотип и домен
должны быть закрашены сплошным прямоугольником #1A2238.
Если не закрашены — останови работу и скажи об этом.
```
