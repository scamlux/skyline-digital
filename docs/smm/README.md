# docs/smm · рабочая папка SMM-машины

| Путь | Что | Кто пишет |
| --- | --- | --- |
| `brain.md` | **единый источник правды**: позиционирование, цены, кейсы, тон, обязательные правила площадок, стоп-лист, стек бесплатных сервисов | владелец + разбор |
| `DESIGN-SYSTEM-POSTS.md` | **дизайн-система постов**: токены, пять шаблонов Ш1–Ш5, ритм сетки, формулы подписей, промпты | из разбора владельца |
| `QA.md` | **контроль качества**: гейт перед публикацией, недельная и месячная сверка, правила отключения форматов | пятничная задача |
| `DESIGN-SYSTEM-POSTS.md` | пять шаблонов постов Ш1–Ш5, токены, правило чередования, формулы текстов | обновляется при смене визуала |
| `FORMATS.md` | **какой пост в каком формате** и почему именно столько слайдов | обновляется при смене раскладки |
| `SCHEDULE.md` | время публикаций по дням, окно ответа на комментарии | раз в месяц по своим данным |
| `SHOT-LIST.md` | какие кадры и данные ждут вставки, задание для агента | по мере закрытия |
| `FIGMA-BUILD-PROMPT.md` | полный промпт для пересборки макетов в Figma | при смене дизайн-системы |
| `PROFILE-CONTENT.md` | **кто мы**: шапка, закреплённая тройка, хайлайты, куда идут восемь проектов | раз в квартал |
| `calendar-2026-09.json` | контент-план месяца, редакция 3 | понедельничная задача, помесячно |
| `state.json` | состояние машины: фаза, подписчики, медианы по форматам, ориентиры-бенчмарки | пятничная сверка |
| `costs.csv` | лог расходов по узлам конвейера | при каждой платной генерации (пока пусто — всё бесплатное) |
| `queue/` | готовые единицы контента | ежедневная задача |
| `prompts/` | готовые промпты для генерации | по необходимости |

## Ритм недели

| День | Рубрика | Шаблон | Тон | Куда |
| --- | --- | --- | --- | --- |
| пн | Разбор | Ш4 плашка | тёмный | Instagram → Telegram, Facebook, Threads |
| ср | Радар | Ш2 бумага | светлый | Instagram → все + PDF-документ EN в LinkedIn |
| пт | Цена вопроса / Кейс | Ш1 слово / Ш5 борд | тёмный | Instagram → все + текстовый пост EN в LinkedIn |
| вс | Вайбкодинг | Ш3 интерфейс | светлый | Instagram → Telegram, Facebook, Threads |

Четыре поста в Instagram и два в LinkedIn в неделю, плюс 3–5 сторис.
Чередование тёмный/светлый держит сетку профиля как шахматную доску.

## Публикация

| Площадка | Чем | Стоимость |
| --- | --- | --- |
| Instagram + Facebook | Meta Business Suite, очередь заранее (глубину проверить в кабинете: 30 или 75 дней) | $0 |
| Telegram | Bot API, бот админом канала | $0 |
| Threads | кросспост из Instagram | $0 |
| LinkedIn | руками с личного профиля, API не существует | 2 минуты × 2 раза в неделю |

## Автоматические задачи

| Когда | Что делает |
| --- | --- |
| вт–сб 09:00 | отдаёт готовый пост дня с подписями и прогоняет его через гейт `QA.md` |
| пн 09:00 | собирает план недели, при необходимости — план следующего месяца |
| пт 17:00 | собирает метрики в `state.json`, применяет правило отключения форматов, проверяет молчаливые провалы очереди |

## Где что делается

| Задача | Инструмент |
| --- | --- |
| Макет, обложки, разборы со скриншотами, кейсы | **Figma** — `scripts/figma/` собирает библиотеку за один запуск |
| Серийное производство постов из JSON | фабрика `scripts/content/` |
| Экспорт в ленту | PNG из Figma → очередь Meta Business Suite |

Макет живёт в Figma, серийное производство — в фабрике. Правка шаблона в Figma переносится в `scripts/content/theme.mjs`, иначе через месяц это две разные дизайн-системы.
