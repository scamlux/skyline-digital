# docs/smm · рабочая папка SMM-машины

| Путь | Что | Кто пишет |
| --- | --- | --- |
| `brain.md` | **единый источник правды**: позиционирование, цены, кейсы, тон, обязательные правила площадок, стоп-лист, стек бесплатных сервисов | владелец + разбор |
| `QA.md` | **контроль качества**: гейт перед публикацией, недельная и месячная сверка, правила отключения форматов | пятничная задача |
| `calendar-2026-09.json` | контент-план месяца, редакция 3 | понедельничная задача, помесячно |
| `state.json` | состояние машины: фаза, подписчики, медианы по форматам, ориентиры-бенчмарки | пятничная сверка |
| `costs.csv` | лог расходов по узлам конвейера | при каждой платной генерации (пока пусто — всё бесплатное) |
| `queue/` | готовые единицы контента | ежедневная задача |
| `prompts/` | готовые промпты для генерации | по необходимости |

## Ритм недели

| День | Что | Куда |
| --- | --- | --- |
| пн | короткий текст | Telegram |
| вт | карусель | Instagram → Telegram, Facebook, Threads |
| ср | короткий текст + PDF-документ EN | Telegram + LinkedIn (личный профиль) |
| чт | карусель | Instagram → Telegram, Facebook, Threads |
| пт | текстовый пост EN | LinkedIn (личный профиль) |
| сб | карусель | Instagram → Telegram, Facebook, Threads |

Семь уникальных единиц в неделю, плюс 3–5 сторис.

## Публикация

| Площадка | Чем | Стоимость |
| --- | --- | --- |
| Instagram + Facebook | Meta Business Suite, очередь заранее (глубину проверить в кабинете: 30 или 75 дней) | $0 |
| Telegram | Bot API, бот админом канала | $0 |
| Threads | кросспост из Instagram | $0 |
| LinkedIn | руками с личного профиля, API не существует | 2 минуты × 2 раза в неделю |

## Автоматические задачи

| Когда | Что делает |
| --- | --- |
| вт–сб 09:00 | отдаёт готовый пост дня с подписями и прогоняет его через гейт `QA.md` |
| пн 09:00 | собирает план недели, при необходимости — план следующего месяца |
| пт 17:00 | собирает метрики в `state.json`, применяет правило отключения форматов, проверяет молчаливые провалы очереди |
