# docs/smm · рабочая папка SMM

## Три файла, с которых всё начинается

| Файл | Что это |
| --- | --- |
| **`content-plan-2026-09.json`** | **единственный источник правды по контенту.** Все 16 постов: даты, время, формат, число слайдов, полные тексты слайдов, подписи. Плюс профиль, сторис, LinkedIn |

## Правила и справочники

| Файл | Что это |
| --- | --- |
| `brain.md` | цены, тон, стоп-лист, обязательные правила площадок, референсы |
| `FORMATS.md` | правило длины: сколько слайдов какому посту и почему |
| `DESIGN-SYSTEM-POSTS.md` | пять шаблонов, токены, формулы текстов |
| `SCHEDULE.md` | время публикаций, окно ответа на комментарии |
| `QA.md` | гейт перед публикацией, недельная и месячная сверка |
| `PROFILE-CONTENT.md` | шапка, закреплённая тройка, хайлайты, сторис «О студии» |
| `SHOT-LIST.md` | какие кадры и данные ждут вставки |
| `state.json` | состояние машины: медианы по форматам, бенчмарки, kill-list |
| `../SMM-ANALYSIS-2026-09.md` | разбор рынка, конкурентов и алгоритмов |

`_архив/` — прежний календарь и раздельные файлы контента. Слиты в единый план, оставлены на случай сверки.

## Порядок работы на месяц

1. **План** — `ПРОМПТ-1` собирает `content-plan-<месяц>.json`
2. **Отрисовка** — `ПРОМПТ-2` строит макеты в Figma по этому плану
3. **Экспорт** — PNG из Figma, либо рендер фабрикой `scripts/content/`
4. **Очередь** — Instagram и Facebook в Meta Business Suite, Telegram ботом, LinkedIn руками
5. **Сверка** — пятничная задача пишет метрики в `state.json` и отключает форматы, которые не работают

Следующий план строится на цифрах из `state.json`, а не на общих соображениях.
