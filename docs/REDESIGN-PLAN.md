# REDESIGN-PLAN — Skyline Digital 2026-Q4

Редизайн skyline-digital.uz: премиальный арт-стиль + рост конверсии. План на ~8 недель (один разработчик + Claude Code).
Статус задач ведём в `TODO.md`, развилки — в `docs/adr/`, подогнанное/додуманное — в `docs/DESIGN-GAPS.md` (правила из `CLAUDE.md` §10).

## 0. Что есть сейчас (снято с прода и репозитория, 2026-10-22)

**Стек:** Next 16.3.1 · React 19 · Tailwind v4 · next-intl (ru/en/uz) · Supabase · Vercel (+ Analytics, Speed Insights) · OpenAI для КП и разбора брифа.
**Не установлено:** framer-motion, three/R3F, React Hook Form. 3D в `ADR 0002` отложен «до замера метрик».
**Дизайн-система:** «Horizon over Tashkent» — ночь `#1a2238`, градиент абрикос→закат, шрифты Unbounded / Golos / JetBrains Mono, CSS-анимации (sunrise-лоадер, reveal, spotlight, marquee).
**Главная сейчас:** hero → 3 цифры (12+ проектов · 5 лет · 2 мин) → 6 услуг с ценой «от» → 4 проекта → «малая команда» → **бегущая строка стека (12 технологий)** → 5 шагов процесса → калькулятор → контакт.
**Воронка:** калькулятор → смета → PDF-КП; `/audit` (аудит сайта) — лид-магнит, лежит только в меню; лиды → Supabase + Telegram.

**Гипотезы по конверсии (проверить в Фазе 0, пока это не факты):**
1. Hero обещает «клиентов», но доказательств рядом нет: цифры «12+ / 5 лет / 2 мин» — не результаты клиентов.
2. Нет отзывов, логотипов клиентов, лица/команды, цифр результата на карточках проектов.
3. Стек занимает целую секцию — клиент покупает результат, а не Vue vs Svelte.
4. Контакт — `pm.umarrr@gmail.com`: для «премиума» нужна почта на домене.
5. `/audit` — сильный магнит, но спрятан.
6. В Узбекистане основной канал — Telegram; он должен быть первичным CTA рядом с калькулятором, а не третьим в футере.
7. Baseline не измерен: гейты §12 (Lighthouse, LCP, CLS, реальные устройства) в `TODO.md` отмечены как «не проверялись».

**Расхождение в доках:** `CLAUDE.md` §4 описывает `/work`, на проде — `/projects`. **URL не меняем** (SEO), `CLAUDE.md` правим под реальность.

## 1. Принципы

- **Арт и конверсия не воюют, если разнести по зонам.** Выразительность — hero, кейсы, переходы. Утилитарная тишина — калькулятор, формы, смета.
- **«Вау» = одна фирменная механика + качество деталей + скорость.** Не десять эффектов. Каждый эффект имеет бюджет и статичный фолбэк.
- **Жёсткие гейты** (из §3/§12, не обсуждаются): LCP ≤ 2.5 с на мобильном 4G, CLS ≤ 0.1, INP ≤ 200 мс, Lighthouse ≥ 90, 3D-чанк ≤ 400 КБ и грузится после первого paint, `prefers-reduced-motion` уважается, 3 локали без пустых ключей. Красивая сцена, которая роняет метрику, считается несделанной.
- **Эволюция бренда, не разрыв:** `theme-color #1a2238`, идея «горизонт над Ташкентом» остаются узнаваемыми.

## Фаза 1. Стратегия и концепт (нед. 1–2, ~4 дня)

1. **Позиционирование и оффер.** Одна фраза, кто и для кого (малый/средний бизнес Узбекистана и СНГ: сайты, приложения, AI) + 3 доказательства. Заголовок hero — 3 варианта на русском, затем uz/en.
2. **Арт-направление — выбрать одно (решает владелец, см. «Решения»):**
   - **A. Editorial Noir** — почти чёрный фон, гигантская типографика (гротеск + контрастный serif-акцент), плёночное зерно, тонкие линии, кейсы на весь экран.
   - **B. Horizon Evolved (рекомендую)** — сохраняем «горизонт/рассвет», но взрослее: глубокая ночь, один шейдерный световой поле-горизонт в hero, редакторская типографика, градиент только как точечный акцент, а не заливка. Сайт «светает» по мере скролла: фон плавно идёт от ночи к рассвету между секциями — буквально *sky-line*.
   - **C. Paper & Type** — светлая бумага, огромный текст, коллажные кейсы, экспериментальная сетка. Самый дерзкий, самый рискованный для B2B-доверия.
3. **Фирменная механика (одна, не больше):** WebGL-горизонт в hero, реагирующий на курсор/гироскоп и скролл (шейдер, а не тяжёлая модель). Всё остальное «вау» — мелкие и дешёвые: магнитные CTA, плавные переходы между страницами (View Transitions API), текст-reveal по строкам, живая цена в калькуляторе.
4. **Новая структура главной (под конверсию):**
   1. Hero: оффер + 2 CTA («Рассчитать за 2 мин» / «Написать в Telegram») + строка доказательств.
   2. Доказательства сразу под hero: логотипы клиентов, 1–2 цифры *результата* (с источником), короткий отзыв.
   3. Избранные кейсы — крупно, с цифрой результата на карточке, одна карточка = один компонент (как сейчас `PreviewCard`).
   4. Услуги с ценой «от» и «что входит».
   5. Лид-магнит `/audit` — отдельный блок, не только пункт меню.
   6. Как работаем — 5 шагов (оставить, сократить текст).
   7. Лицо студии: портрет/команда, 2–3 фразы, гарантии (код в вашем репозитории с первого дня, фикс-цена, N правок).
   8. FAQ (цена, сроки, оплата, поддержка) + JSON-LD.
   9. Финальный CTA: калькулятор + Telegram + телефон.
   - **Стек** уезжает с главной на `/about`. **Sticky-панель CTA** на мобильном (Telegram + «Рассчитать»).
5. **Калькулятор как флагман:** живая цена видна с 1-го шага, сохранение прогресса, контакт — в самом конце, телефон/Telegram-first, невидимая капча. Тихий, функциональный UI без тяжёлых эффектов.
6. **Конверсионные правки вне дизайна:** почта на домене (`hello@skyline-digital.uz`), реквизиты в футере, обещание времени ответа (только если выполнимо), авто-ответ клиенту после заявки.

**Гейт:** ADR `0005-art-direction.md` (выбранное направление) и `0006-3d-hero.md` (закрывает ADR 0002), список секций главной утверждён.

## Фаза 2. Дизайн (нед. 2–3, ~8 дней)

1. **Дизайн-система → токены.** Цвет (тёмная/светлая темы, `color-scheme` уже заявлен), типографика (fluid-шкала), сетка 12 кол., отступы, радиусы, тени, motion-токены (длительности, easing). Всё в `src/styles/tokens.css`/`@theme`, **без хардкода** в компонентах.
   - **Риск шрифтов:** дисплейный шрифт обязан поддерживать кириллицу *и* узбекскую латиницу с `ʻ` (U+02BB), `Oʻ`, `Gʻ`, а также `Ў Ғ Қ Ҳ`. Проверить глифы до утверждения шрифта (в репо уже есть тест глифов — расширить). Только бесплатные/OFL-лицензии.
2. **Макеты в Figma** (через Figma MCP; если файл недоступен — по скриншотам в `design/` и запись в `DESIGN-GAPS.md`): главная, `/services` + деталка, `/projects` + деталка (кейс-ленд), `/about`, `/contact`, `/calculator` (все шаги), `/estimate/[token]`, `/audit`, 404. Десктоп 1440 и мобильный 390.
3. **Motion-спека:** что анимируется, чем, с какой длительностью, что отключается при `reduced-motion`, что упрощается на мобильном (poster/статичный градиент вместо WebGL).
4. **3D/WebGL-прототип** отдельно от сайта: шейдер-горизонт, замер веса и FPS на среднем Android до начала вёрстки. Вес цели ≪ 400 КБ (лёгкая WebGL-либа/сырой шейдер вместо полного three; R3F только если реально нужен scene graph).
5. **Кейс-страницы:** шаблон «длинного кейса» — hero с обложкой, цифры, задача→решение→результат, галерея, цитата клиента, CTA «Хочу так же» → калькулятор с предвыбранной услугой.
6. **Копирайтинг на 3 языках** (ru первым, затем uz/en; скиллы `copywriting`, `contento-brand-voice`/`uz-text` для узбекского): hero, услуги, FAQ, кейсы. Длина узбекского/русского длиннее английского — макеты проверяем на самом длинном.
7. **Ревью дизайна:** `design:design-critique`, `design:accessibility-review` по макетам (контраст AA ещё на этапе палитры).

**Гейт:** макеты всех экранов утверждены владельцем; прототип WebGL уложился в бюджет на реальном телефоне; токены экспортированы.

## Фаза 3. Разработка (нед. 3–6)

Ветка на спринт → PR в `main` → превью на Vercel (правила `CLAUDE.md` §10). Перед кодом — прочитать актуальные доки Next 16 из `node_modules/next/dist/docs/` (в `CLAUDE.md` предупреждение: API отличаются от привычных).

**Спринт 1 (нед. 3) — фундамент**
- Токены, тема, шрифты (`next/font`, subset кириллица+латиница, `font-display: swap`), базовые компоненты (`Button`, `Section`, `Card`, `Reveal`).
- Motion-слой: `motion` (Framer Motion) для UI; GSAP/ScrollTrigger — только если нужен scroll-linked «рассвет» (проверить лицензию и вес).
- Header/Footer/CTA-панель, мобильное меню, переключатель языка.
- Трекинг событий (§0.2) подключён сразу, чтобы мерить «после».

**Спринт 2 (нед. 4) — главная**
- Hero + WebGL-горизонт (`dynamic(..., { ssr: false })`, старт после первого paint, `IntersectionObserver`, пауза вне экрана, DPR cap, фолбэк: статичный градиент-постер при `reduced-motion`, слабом устройстве, `saveData`, мобильном).
- Секции доказательств, кейсы, услуги, audit-блок, FAQ, финальный CTA.
- Прелоадер: убрать или ≤ 600 мс — он съедает LCP.

**Спринт 3 (нед. 5) — кейсы, услуги, калькулятор**
- `/projects`, `/projects/[slug]` (ISR `revalidate: 60`, переходы между кейсами), `/services/[slug]`, `/about`, `/contact`.
- Калькулятор: перестройка шагов, живая цена, сохранение прогресса, переходы между шагами; `/estimate/[token]` — в новой системе, `noindex`.
- Движок цен **не трогаем** без Vitest (правило §7/§10); визуал не должен менять суммы.

**Спринт 4 (нед. 6) — полировка**
- Page transitions (View Transitions API), курсор/magnetic — только desktop `pointer: fine`.
- OG-картинки, JSON-LD (Organization, Service, CreativeWork, FAQ), sitemap/hreflang без изменений URL.
- Оптимизация: размеры изображений, AVIF/WebP, `priority` только на LCP-элементе, разбиение чанков, удаление неиспользуемого CSS/JS.
- Админка не редизайнится (вне объёма), только совместимость токенов.

**Definition of Done задачи:** `pnpm/npm typecheck && lint && build && test` зелёные + скриншоты 1440/390 в `screenshots/` + проверка глазами против макета + запись в `TODO.md`.

## Фаза 5. Прод (нед. 7–8) и после запуска

**Подготовка**
- Staging = Vercel Preview на ветке редизайна; финальный контент ×3 языка; переменные окружения сверены (`TURNSTILE_*`, Upstash, `CRON_SECRET`, Supabase).
- Бэкап БД перед релизом. Миграции: редизайн схему не меняет (если появятся поля отзывов/метрик кейсов — миграция идёт *до* деплоя, обратимая).
- Редиректы не нужны (URL сохранены); проверить, что внутренние ссылки/`canonical`/`hreflang` не изменились.

**Запуск**
1. Заморозка контента за 48 ч, финальный прогон Фазы 4 на превью.
2. Merge в `main` в будний день утром по Ташкенту (не в пятницу вечером).
3. Проверка прода: smoke-тест воронки живой заявкой (калькулятор + контакт + Telegram-уведомление + PDF), Lighthouse на проде.
4. Ресабмит sitemap в Search Console и Яндекс.Вебмастер; обновить OG-кэш (Telegram, LinkedIn).
5. **Откат:** Instant Rollback на предыдущий деплой в Vercel; критерий — падение отправки заявок, LCP > 4 с, ошибки в Sentry.

**Мониторинг**
- Первые 48 ч: Sentry/runtime-логи, поток заявок, Speed Insights (RUM, реальные пользователи).
- 7 / 14 / 30 дней: сравнение с baseline (Фаза 0) по KPI, позиции в поиске, реплеи сессий.
- На 30-й день — ретро: что оставить, что упростить, следующий цикл гипотез (заголовки, порядок секций, шаги калькулятора).

## Риски

| Риск | Что делаем |
|---|---|
| WebGL роняет LCP/батарею на бюджетных телефонах | Грузим после paint, шейдер вместо моделей, пауза вне экрана, DPR cap, постер на мобильном/`saveData`/`reduced-motion`; метрики в CI |
| «Арт» ухудшает конверсию | Выразительность только в hero/кейсах; калькулятор и формы тихие; сравнение с baseline на 7/14/30 день, быстрый откат отдельных эффектов |
| Нет доказательств для блока социального доказательства | Фаза 0.7–0.8; вместо выдуманных цифр — «требует подтверждения» (правило фактов из `CLAUDE.md` соседних проектов) |
| Шрифт не покрывает uz-глифы | Проверка глифов в Фазе 2 до утверждения |
| Потеря SEO | URL и метаданные сохраняем, ресабмит sitemap, мониторинг позиций |
| Мало трафика → A/B бессмысленен | Реплеи + интервью + до/после; тесты только если трафика хватает |
| Скоуп расползается («ещё эффект») | Бюджет эффектов зафиксирован в motion-спеке; новое — только через ADR |

## Решения владельца (нужны до Фазы 2)
