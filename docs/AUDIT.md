## 🔴 Критичные ТЗ-разрывы (нарушение §2 «не обсуждается»)

### 1. AI на OpenAI, а не Anthropic — `критично`
`src/lib/ai/client.ts` использует `openai` (`gpt-4o-mini`, ключ `OPENAI_API_KEY`). ТЗ §2 (стек «не обсуждается») и §8 требуют **Anthropic Messages API, модель `claude-sonnet-4-6`, ключ только в `ANTHROPIC_API_KEY`**. Ни `@anthropic-ai/sdk`, ни `ANTHROPIC_API_KEY` нигде нет.
→ *Заменить SDK на `@anthropic-ai/sdk`, structured output через tool-use, переименовать env. Требует ADR. Решение владельца.*

### 2. 3D отсутствует полностью — `критично`
Нет `three` / `@react-three/fiber` / `@react-three/drei` в зависимостях. §3 объявляет 3D **обязательной частью** (крупная 3D-сцена в hero, 3D-акценты на карточках). Анимации сделаны на CSS. Единственное упоминание «Three.js» — строка в `src/data/stack.ts`.
→ *Либо реализовать R3F-hero, либо ADR, официально понижающий 3D до CSS. Решение владельца.*

### 3. Админка отсутствует целиком — `критично` (крупнейший функциональный разрыв)
Нет ни одного `/admin/*` роута, нет Supabase Auth, нет `@supabase/ssr`. Каскадом отваливается вся «контентная половина» продукта из §5/§6:
- Проекты **захардкожены** в `src/data/projects.ts` (8 записей в TS-массиве), а не читаются из Supabase. Таблицы `projects` в БД нет вовсе.
- Нет добавления/редактирования проектов и прайса без деплоя (ровно тот сценарий, ради которого §5 писался).
- Нет AI-предзаполнения карточек проекта (touchpoint C §8), нет бейджей «ИИ», нет черновиков/публикации.
→ *Самый большой объём работ. Решение владельца по приоритету.*

## 🔴 Движок цен (§7) — по сути другая модель

Совпало ровно одно: срочность **×1.35** ✅. Остальное расходится:

| # | Находка | Ожидание §7 | Факт |
|---|---|---|---|
| P1 | Вилка цены | `[total×0.9, total×1.15]` (−10%/+15%) | симметрично ±12% (`rules.ts` rangeSpread 0.12) |
| P2 | Опции | `Σfixed + Σ(base×percent) + Σ(per_unit×qty)` | только `fixed`; нет percent/per_unit → «доп.язык 12%», «копирайтинг 25/стр», «срочный 35% как опция» невыразимы |
| P3 | Недели | `ceil((base_days + Σdays_delta)/5)`, вилка ±1 | веса недель + сжатие ×0.7 при срочности; нет дней, нет `/5`, нет вилки недель |
| P4 | Каталог услуг | 10 услуг §7 (Лендинг 450/7д … Техподдержка 120) | другая таксономия (website 700, webApp 1500…), 0 услуг засеяно (нет таблицы) |
| P5 | Опции-каталог | 12 опций §7 с типами | 0 засеяно; ключи и суммы другие |
| P6 | Валюта UZS | из `settings.fx_rate` (12000, редактируемо) | движок даёт только USD; `FX_RATE=12000` захардкожен в шаблоне КП |
| P7 | `price_snapshot` | копия прайса на момент расчёта | не хранится; заморожены только итоговые числа в `pricing_result` |

⚠️ Правки движка меняют реальные цифры в выданных клиентам сметах и завязаны на прайс, который сам по себе «черновой, ждёт сайн-оффа владельца». **Не трогаю без решения владельца.**
